# DATT4700CAPSTONEVR

Unity VR Capstone Project

## Setup Instructions

1. Clone this repository
2. Open the project in Unity Hub
3. Ensure you have the required Unity version installed

## Project Structure

- `Assets/` - All game assets, scripts, and scenes
- `ProjectSettings/` - Unity project settings
- `Packages/` - Unity package dependencies

## Getting Started

This is a Unity VR project. Open the project in Unity and navigate to the scenes in `Assets/Scenes/`.
